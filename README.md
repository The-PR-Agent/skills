# The-PR-Agent Skills

Reusable skills for AI agents that work with [PR-Agent](https://github.com/The-PR-Agent/pr-agent).

## Available skills

- [`pr-agent-review`](pr-agent-review/SKILL.md): choose and run PR-Agent review commands safely, with configuration and validation guidance.

Skills are distributed as directories containing a `SKILL.md` file. Copy a skill directory into the skills directory supported by your agent.
